## 主动反馈

WSL 调用 Windows 通知服务的一次测试返回成功；通知内容通过编码 XML 传递。
该返回值证明系统接受了投递请求，不能证明用户实际看到弹窗。
通知同时保存在私有 SQLite 收件箱，投递失败保留错误；`follow` 提供不调用模型的简洁事件流。
未验证原生 Codex 窗口自动显示跨会话消息。
